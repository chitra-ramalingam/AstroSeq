  science_binary_v3 == science_like -> binary target 1 / positive
  science_binary_v3 == not_science_like -> binary target 0 / negative
  science_binary_v3 == unresolved -> excluded from binary training

Label families:
  science_like: planet_like, candidate_like
  not_science_like: noise_or_artifact, binary_system, variable_or_artifact,
                    low_priority_negative
  unresolved: uncertain_hold / manual hold rows

5. Unresolved / uncertain_hold treatment
----------------------------------------
unresolved / uncertain_hold rows should be excluded from binary training.
They may be retained only for evaluation, calibration, ranking sanity checks,
or hold-queue analysis. This matches the current v3 scoring logic, which
excludes uncertain_hold rows from tuning metrics.
